CV Screening - Setup Instructions (Windows and Mac)
====================================================

You need: this folder, the small file "key.txt" we sent you, and about 15
minutes.

Nothing else has to be installed first. The installer brings its own private
copy of Python 3.12 - it never uses or changes the Python already on this
computer (Apple M1/M2/M3/M4 and Intel are all handled automatically), needs no
administrator rights, and installs nothing system-wide.

STEP 0 - GET READY (30 seconds)
-------------------------------
1. Double-click the zip and keep the unzipped folder named
   "CV-Screening-Setup" in your Downloads folder - the commands below use
   that location.
2. Put the file "key.txt" we sent you INSIDE this folder, next to setup.bat.
   The installer reads it automatically and deletes it afterwards - you never
   need to type or paste the key anywhere.

The first run downloads about 50 MB (the installer helper and the private
Python) and then the screening components. This happens once.


WINDOWS
-------
1. Double-click  setup.bat
   (If the window closes instantly, open Command Prompt and paste:
       cd /d "%USERPROFILE%\Downloads\CV-Screening-Setup"
       setup.bat
    so any error message stays visible.)
2. Wait for the two lines:
       Self-test passed - the screening engine works on this computer.
       Install complete.
3. Quit WorkBuddy completely and open it again.
4. Open  Experts -> My Experts -> Vera  and say:
       screen refno 260901004
   (a demo job, safe to try). Reports appear on your Desktop in the folder
   workbuddy-cv-screen.


MAC - EASIEST: let WorkBuddy install it for you
-----------------------------------------------
You never touch Terminal, and your key never appears in any chat.

1. Open WorkBuddy and start a NEW conversation (any assistant).
2. Paste this message:

   請幫我安裝 CV 篩選引擎：在 ~/Downloads/CV-Screening-Setup 資料夾裡執行
   bash setup.command。key.txt 已在資料夾內，安裝器會自動讀取並刪除；
   完成後回報結果。

3. When it finishes, quit WorkBuddy completely and open it again.
4. Open  Experts -> My Experts -> Vera  and say:
       screen refno 260901004


MAC - ALTERNATIVE: one line in Terminal
---------------------------------------
1. Open Terminal (Applications -> Utilities -> Terminal) and paste:

   cd ~/Downloads/CV-Screening-Setup && bash setup.command

2. Wait for  Self-test passed  and  Install complete.
3. Quit WorkBuddy completely and open it again, then open Vera and say:
       screen refno 260901004


UPDATES
-------
New versions are published on GitHub. The expert checks quietly before each
screening session and applies updates automatically; your API key, saved
conditions and past reports are always kept. You can also update manually:
double-click  update_engine.cmd  (Windows) or  update_engine.command  (Mac).


PRIVACY
-------
Reports show application numbers only - no names, emails, phone numbers,
HKIDs or salaries. CV files stay on this computer. The API key is stored
only in the local configuration file inside this folder.


TROUBLESHOOTING
---------------
- Setup could not download something: check the internet connection (the
  downloads come from github.com and pypi.org) and run setup again.
- The window closes instantly: follow the Command Prompt / Terminal variant
  shown above, so the error message stays visible.
- Screening fails with an authentication error: your key.txt was missing or
  invalid. Save the key as key.txt inside the agent-cv-screening folder
  (next to setup.bat) and run setup again - or edit the ZAI_API_KEY line in
  the .env file there.
- Expert missing in WorkBuddy: restart WorkBuddy; if it is still missing,
  run setup again.
- Mac: screening the internal PolyU job pages needs the Windows browser
  bridge; on Mac the public demo jobs work.
