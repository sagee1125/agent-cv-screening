CV Screening - Setup Instructions (Windows and Mac)
====================================================

You need: this folder, your personal API key (in the encrypted spreadsheet we
sent you), and about 15 minutes.

Nothing else has to be installed first. The installer brings its own private
copy of Python 3.12 - it never uses or changes the Python already on this
computer (Apple M1/M2/M3/M4 and Intel are all handled automatically), needs no
administrator rights, and installs nothing system-wide.

Each person has their own key. When the installer asks for it, paste YOUR key.
The input is hidden on screen - that is normal.

IMPORTANT: unzip this folder into your **Downloads** folder and keep the
folder name "CV-Screening-Setup". The commands below use that location.

The first run downloads about 50 MB (the installer helper and the private
Python) and then the screening components. This happens once.


WINDOWS
-------
1. Double-click  setup.bat
2. When it asks for your personal API key, paste it and press Enter
   (the input is hidden on screen - that is normal).
3. Wait for the two lines:
       Self-test passed - the screening engine works on this computer.
       Install complete.
   (If the window closes instantly, open Command Prompt and paste:
       cd /d "%USERPROFILE%\Downloads\CV-Screening-Setup"
       setup.bat
    so any error message stays visible.)
4. Quit WorkBuddy completely and open it again.
5. Open  Experts -> My Experts -> Vera  and give it a real internal job
   number, for example:
       screen refno 26xxxxxxxxx
   This screens the University's internal job pages - stay on the campus
   network (or VPN) and stay signed in to the internal job system in Chrome.
   Reports appear on your Desktop in the folder  workbuddy-cv-screen.
   (To try the public demo instead, first add  JES_SITE_MODE=0  to the .env
   file as described in "Which jobs are screened" below, then say:
       screen refno 260901004 )

   - If you see an error message, or nothing happens, or the window closes
     immediately: use the guaranteed fallback below (step 2). It takes one
     pasted line and always works.
2. Guaranteed fallback - open Terminal (Applications -> Utilities ->
   Terminal), paste this ONE line and press Enter:

3. When it asks for your personal API key, paste it and press Enter

   (To try the public demo instead, first add  JES_SITE_MODE=0  to the .env

UPDATES
-------
New versions are published on GitHub. The expert checks quietly before each
screening session and applies updates automatically; your API key, saved
conditions and past reports are always kept. You can also update manually:
double-click  update_engine.cmd  (Windows) or  update_engine.command  (Mac).


PRIVACY
-------
Reports show application numbers only - no names, emails, phone numbers,
HKIDs or salaries. CV files stay on this computer. Your API key is stored
only in the local configuration file inside this folder - never share it,
and never paste it into a chat conversation.


WHICH JOBS ARE SCREENED
-----------------------
Out of the box this package screens the University's INTERNAL job pages.
Screening them needs two things at the time of a run: you are signed in to the
internal job system in Chrome, and the computer is on the campus network or
connected to the University VPN.

To screen the public DEMO jobs instead (no sign-in or VPN needed), open the
file named  .env  inside the agent-cv-screening folder (Notepad on Windows,
TextEdit on Mac) and make its  JES_SITE_MODE  line read:

    JES_SITE_MODE=0

Save the file. Change the line back to  JES_SITE_MODE=1  (or delete it) to
return to the internal pages.


TROUBLESHOOTING
---------------
- Setup could not download something: check the internet connection (the
  downloads come from github.com and pypi.org) and run setup again.
- The window closes instantly: follow the Command Prompt / Terminal variant
  shown above, so the error message stays visible.
- Screening fails with an authentication error: your key was not saved
  correctly. Run setup again and paste your key when asked - or edit the
  ZAI_API_KEY line in the .env file inside the agent-cv-screening folder.
- Expert missing in WorkBuddy: restart WorkBuddy; if it is still missing,
  run setup again.
- Screening the internal pages fails: check the campus network / VPN, and
  that you are signed in to the internal job system in Chrome. To fall back
  to the public demo jobs while troubleshooting, set  JES_SITE_MODE=0  in the
  .env file (see "Which jobs are screened").
