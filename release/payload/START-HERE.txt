CV Screening - Setup Instructions (Windows and Mac)
====================================================

You need: this folder, the API key we sent you, and about 15 minutes.

Nothing else has to be installed first. The installer brings its own private
copy of Python 3.12 - it never uses or changes the Python already on this
computer (Apple M1/M2/M3/M4 and Intel are all handled automatically), needs no
administrator rights, and installs nothing system-wide.

STEP 0 - UNZIP
--------------
Double-click the zip. Keep the unzipped folder named "CV-Screening-Setup" in
your Downloads folder - the commands below use that location.


WINDOWS
-------
1. Double-click  setup.bat
2. When it asks, paste the API key we sent you, then wait.
   A lot of text scrolls by - that is normal. Wait for the two lines:
       Self-test passed - the screening engine works on this computer.
       Install complete.
3. Quit WorkBuddy completely and open it again.
4. Open  Experts -> My Experts -> Vera  and say:
       screen refno 260901004
   (a demo job, safe to try). Reports appear on your Desktop in the folder
   workbuddy-cv-screen.

If the window closes instantly, open Command Prompt and paste:
    cd /d "%USERPROFILE%\Downloads\CV-Screening-Setup"
    setup.bat


MAC - EASIEST: let WorkBuddy install it for you
-----------------------------------------------
You never touch Terminal. WorkBuddy runs the installer for you.

1. Open WorkBuddy and start a NEW conversation (any assistant).
2. Paste this message, replacing PUT-YOUR-KEY-HERE with your API key:

   請幫我安裝 CV 篩選引擎：把 ~/Downloads/CV-Screening-Setup/setup.command
   加上執行權限（chmod +x），清除隔離屬性（xattr -d
   com.apple.quarantine，如檔案存在），然後以
   CVS_API_KEY="PUT-YOUR-KEY-HERE" 執行
   bash ~/Downloads/CV-Screening-Setup/setup.command
   （工作目錄為該資料夾），完成後回報結果。

3. When it finishes, quit WorkBuddy completely and open it again.
4. Open  Experts -> My Experts -> Vera  and say:
       screen refno 260901004


MAC - ALTERNATIVE: paste one line into Terminal
-----------------------------------------------
1. Open Terminal (Applications -> Utilities -> Terminal).
2. Paste this ONE line, replacing PUT-YOUR-KEY-HERE with your API key:

   cd ~/Downloads/CV-Screening-Setup && CVS_API_KEY="PUT-YOUR-KEY-HERE" bash setup.command

3. When it finishes, quit WorkBuddy completely and open it again, then open
   Vera and say:  screen refno 260901004


UPDATES
-------
New versions are published on GitHub. The expert checks quietly before each
screening session and applies updates automatically; your API key, saved
conditions and past reports are always kept. You can also update manually:
double-click  update_engine.cmd  (Windows) or  update_engine.command  (Mac).


PRIVACY
-------
Reports show application numbers only - no names, emails, phone numbers,
HKIDs or salaries. CV files stay on this computer.


TROUBLESHOOTING
---------------
- Setup could not download something: check the internet connection (the
  downloads come from github.com and pypi.org) and run setup again.
- The window closes instantly: use the Command Prompt variant shown above
  (Windows) so the error message stays visible.
- Mac: "cannot be opened because it is from an unidentified developer" -
  use the "let WorkBuddy install it" route above; it bypasses this entirely.
- Expert missing in WorkBuddy: restart WorkBuddy; if it is still missing,
  run setup again.
- Mac: screening the internal PolyU job pages needs the Windows browser
  bridge; on Mac the public demo jobs work.
